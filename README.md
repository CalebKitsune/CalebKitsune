# Hi, I'm Caleb Dufour

**Computer Engineering @ UC Riverside | Embedded Systems & Firmware**

I enjoy building software that interacts with real hardware—and understanding what happens beneath the abstraction layers. My interests include **embedded C/C++, microcontrollers, real-time systems, and hardware/software integration**.

I approach projects with a simple question: *Does it work, and how can I verify that it works?* That has led me from writing GPIO drivers to measuring RTOS task timing with an oscilloscope.

## What I've worked on

### [ESP32-C6 • FreeRTOS scheduling and timing experiments](https://github.com/CalebKitsune/FreeRTOS-Scheduling-Analysis)

- Developed periodic tasks in **ESP-IDF/FreeRTOS**, using GPIO signals to study task execution at different intervals.
- Investigated how task priorities and computational load affect scheduling behavior.
- Used a **Siglent oscilloscope** to inspect timing and connect software behavior to physical measurements.

*Project documentation and source publication in progress.*

### [STM32 GPIO HAL](https://github.com/CalebKitsune/CustomSTM32H7S3L8GPIOHAL)

Exploring GPIO control on the **STM32H7S3L8**, with an emphasis on peripheral configuration, register-level behavior, and reusable abstractions.

### [STM32 Blinky & LED Driver](https://github.com/CalebKitsune/BlinkyGithub)

Hands-on STM32 development with GPIO and LED control, paired with a separate [C++ LED driver](https://github.com/CalebKitsune/LED_Driver).

### [ESP32 Stepper Motor Control](https://github.com/CalebKitsune/ESP32_28BYJ-48)

An **ESP-IDF** project exploring firmware control of a **28BYJ-48 stepper motor**.
